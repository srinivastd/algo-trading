What goes in CSV / Run ID / Strategy params?
  • CSV file — Optional filename only, under historical_data/ (e.g. NVDA-2023-01-01-2026-04-28-15mins.csv). Empty = use newest file for symbol + bar size (see list after Refresh lists).
  • Run ID — Optional trade_journal.runs.run_id from a watch/paper session. Loads stored params_json into the strategy (same knobs as that run). “Load params from run” copies them into the JSON box. Not the data file: bars still come from the CSV.
  • Strategy params (JSON) — Optional overrides for GroqRecommendationsStrategy (e.g. adx_min, zone_lookback). Applied on top of Run ID. Logs and Chroma are not read for params—only the journal run row or this JSON.
  • Day (ET) — Defaults to browser “today” on load. Must be a calendar day that has at least one bar in the selected CSV (see cache_index_start / cache_index_end in meta after a successful chart).
